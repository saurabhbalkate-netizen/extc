HOW TO RUN IN TURBO C++
-----------------------
1. Copy all .CPP files to the Turbo C++ BIN folder (or any working folder).
2. Start Turbo C++ (TC.EXE).
3. File > Open (F3) and choose the program file.
4. Press Alt+F9 to compile.
5. Press Ctrl+F9 to run.
6. Press Alt+F5 to view the output screen again if needed.
